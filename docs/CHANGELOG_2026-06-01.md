# 开发日志 2026-06-01

## 概述
本次更新围绕「首页看板重构」「周例会记录模式」「项目进展反馈联动」「长期项目」以及一系列交互打磨展开，并新增腾讯云部署手册。核心目标是让看板更聚焦待关注事项、让项目进展可追踪可反馈、并简化项目录入流程。

---

## 1. 首页看板重构为三个关注分区

### 改动
- 图表区下方由「单一项目列表 + 筛选」改为三个分区（[ProjectBoardView.vue](../frontend/src/views/ProjectBoardView.vue)）：
  - **重点项目**：优先级为「重要 / 高」，重要在前、高在后
  - **等待关注**：最新进展为 待讨论 / 待确认 / 待执行
  - **延迟关注**：最新进展为 延迟
- 仅展示「进行中」项目；项目可同时出现在多个区
- 卡片边缘色按区/优先级：重要=红、高=暗红、等待=蓝、延迟=橙
- 卡片右上角显示最新进展状态【正常】【延迟】等（颜色一致）
- 卡片悬停弹出最近 8 条进展（超过则顶部「……」，周会记录带蓝色标识）
- 恢复「卡片 / 列表」视图切换，按钮与「重点项目」标题对齐，分区间分割线
- 顶部两图表改为「各部门项目数量」（环状图 + 引导线标注）、「各负责人项目数量」（柱状图）
- 点击卡片改为打开项目详情抽屉（不再跳旧任务页）

## 2. 周例会记录模式

### 数据 / 后端
- 新建 `system_settings`（key-value）通用配置表 + 迁移
- `ProgressEntry` 增加 `meeting_session`（周会次数）
- [settings_service.py](../backend/services/settings_service.py)：周会次数按自然周递增算法、进展记录扫描、状态组装
- [settings.py](../backend/api/v1/settings.py)：`GET /settings/meeting`（全员）、`PUT .../active`、`PUT .../count`（仅管理员）

### 前端
- Pinia `meetingStore` + `settingsApi`
- 顶栏「周例会」开关：管理员可切换（提示进入/已在周例会状态），非管理员只读
- 详情页周会模式右上角「第 N 次周会记录中……」，进展输入框前「周会记录：」标签，保存自动打 `meeting_session`，时间线显示「【第N次周会更新】」
- 系统设置新增「其他设置」tab：展示本周/上次周会信息，管理员可校准次数
- 顶栏周会记录按钮 + 周会自动记录弹窗（按项目排序汇总当次周会各项目最新进展，「发送会议记录」占位）

## 3. 项目进展反馈联动

### 数据
- `ProgressEntry` 增加 `id`、`reply_to`（反馈事件指向原事件 id），向后兼容老数据

### 交互（[ProjectDetailDrawer.vue](../frontend/src/components/ProjectDetailDrawer.vue)）
- 未结束事件（待讨论/待确认/待执行）时间线显示**空心闪烁圆点**
- 编辑态未结束事件可点「反馈」按钮，插入反馈草稿（继承状况、内容前「反馈：」标签）
- 有反馈后原事件停止闪烁；反馈事件为实心点，颜色继承原事件
- 反馈状态文字：讨论已反馈 / 确认已反馈 / 执行已反馈
- **反馈连线**：SVG 测量节点真实位置绘制「弧出 → 左侧平行虚线 → 弧入」，不与主时间轴重合；重叠连线自动错开到不同平行车道（至少 2 层，不足则重叠）

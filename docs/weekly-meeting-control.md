# 周例会·主控与结束/退出 操作说明

本文说明周例会「汇报模式」的角色与控制权限：谁能控制计时、谁能**结束会议**、谁只能**退出**、掉线/接管如何处理。面向运行周会的管理员。

> 相关代码：[meeting_records.py](../backend/api/v1/meeting_records.py)（开启/结束/计时路由）、[meeting_timer_service.py](../backend/services/meeting_timer_service.py)（主控/计时状态机）、[MeetingReportView.vue](../frontend/src/views/MeetingReportView.vue) / [MeetingTopBar.vue](../frontend/src/components/meeting-report/MeetingTopBar.vue)（汇报页 UI）。

---

## 1. 进入与角色

- **谁能进入汇报页**：管理员，且周会模式已开启。入口在看板顶部「周例会」区的全屏按钮（`进入周会汇报`）。普通成员不进入此页。
- **主控端（控制者）**：进入汇报页的管理员会自动「认领主控」。**第一个进入的管理员成为主控**；其余管理员进入时已有主控，则为**协助端**。
- **协助端**：可自由浏览项目、查看计时与统计，但**不能控制计时**、**不能结束会议**，只能**退出**（或在主控掉线后**接管控制**）。
- 角色显示在汇报页右上角：`● 主控` / `● 协助中` / `主控已掉线`。

| 能力 | 主控端 | 协助端 |
|---|:---:|:---:|
| 控制计时（▶ 开始/继续、❚❚ 暂停、切换汇报人计时） | ✅ | ❌ |
| 浏览项目 / 查看用时统计 | ✅ | ✅ |
| **结束会议** | ✅ | ❌ |
| **退出会议** | ✅ | ✅ |
| 接管控制（仅主控掉线释放后） | — | ✅ |

---

## 2. 结束会议 vs 退出会议（核心）

### 结束会议（仅主控端）
- **只有主控端**能看到并点击「结束会议」。
- 作用：归档本次周会、写入结束时间、**关闭周会模式**、清空计时——**影响所有参会端**，会议真正结束。
- 后端强校验：结束请求带本端 `client_id`，**存在主控时只有主控的 `client_id` 能结束**，否则返回 `403 仅主控端可结束本次周会`。
- 兜底：当**无主控**（主控已释放、或从未有人认领）时，任意管理员可结束（用于清理卡死的会议）。

### 退出会议（任何端）
- 任何端（含主控）都能点「退出会议」。
- 作用：**仅离开本端的汇报视图**，停掉本端的计时刷新/心跳；**不结束会议、不影响其他参会端的进程**。
- **可随时再加入**：退出后回到看板，再次点「进入周会汇报」即可重新进入，自动恢复主控/协助角色（不打断会议）。

> 还有一条结束入口：看板顶部「周例会」开关关掉，也会结束会议——同样受上面的主控校验，非主控点了会被拒绝（开关自动回弹并提示）。

## 3. 主控掉线、接管与刷新续权

主控端每 5 秒发一次心跳。基于心跳判断（[meeting_timer_service.py](../backend/services/meeting_timer_service.py)）：

- **掉线自动暂停**：心跳中断超过 **15 秒** → 判为掉线，**计时自动暂停**（掉线期间不计时），顶部出现掉线横幅，等待重连。
- **重连自动继续**：主控在释放前回来（同一浏览器 `client_id`），心跳恢复后**计时自动继续**。
- **释放与接管**：心跳中断超过 **3 分钟** → 释放主控控制权，协助端出现「接管控制」按钮，点击即可成为新主控，随后即可控制计时/结束会议。
- **主控刷新续权**：主控刷新页面不会丢失控制权——同一浏览器用同一 `client_id` 重新认领，仍是主控。

> 客户端身份 `client_id` 按浏览器持久化（localStorage，见 [utils/meetingClient.ts](../frontend/src/utils/meetingClient.ts)），跨「汇报页 / 看板开关」共用，用于主控续权与结束校验。

## 4. 常见场景

- **临时离开但会议继续**：点「退出会议」→ 处理别的事 → 回看板点「进入周会汇报」重新加入。会议进程不受影响。
- **协助管理员想结束会议**：需先等主控掉线释放（3 分钟后）→ 点「接管控制」成为主控 → 再「结束会议」；或由主控端直接结束。
- **主控电脑死机/关页**：3 分钟后控制权释放，其他管理员可「接管控制」继续主持，或在看板用开关结束（无主控兜底允许）。
- **点结束被提示「仅主控端可结束本次周会」**：说明你不是当前主控。请由主控端结束，或按上一条接管后再结束。

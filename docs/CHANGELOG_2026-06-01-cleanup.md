## 二、本阶段交付的功能

### 1. 项目进展反馈联动（详情页）
- `ProgressEntry` 增加 `id` / `reply_to`，建立「未结束事件 → 反馈」一对一关联。
- 时间线：待讨论/待确认/待执行显示**空心闪烁圆点**；有反馈后停止闪烁、反馈点为实心、并以 **SVG 平行虚线段 + 圆弧**连接（多车道避让重叠）。
- 编辑态对未结束事件提供「反馈」按钮，反馈状态文字显示为「讨论/确认/执行 已反馈」。

### 2. 长期项目
- `Project` 增加 `is_long_term`；勾选后详情/总览/看板均以「长期项目」替代完成度。

### 3. 记录日期自动化
- 创建项目时由后端自动记录为当天，移除记录日期编辑组件，详情页右上角显示「记录于 …」。

### 4. 数据库全量导出 / 导入
- JSON 快照全量导出；上传导入为**事务内全量替换**，失败回滚。
- 仅管理员，入口在「系统设置 › 其他设置」。后端 `backup_service` + `backup` 路由 + 8 项测试。

### 5. 进展停滞标识
- 项目总览按「最新进展距今天数」7 档配色显示 `⏱N` 标签，>90 天整行淡红背景；无进展记录显示灰色斜体提示。
- 详情页标题挂同款停滞标签 + 下方居中横幅，天数颜色随时长加深。
- 进展列新增「按最新进展状态筛选」。

### 6. 首页信息看板重构
- 三个关注分区（重点 / 等待关注 / 延迟关注），卡片悬停看最近 8 条进展、右上角显示最新进展状态。
- 统计卡片：项目总数 / 进行中 / 已完成 / 待确认项目 / **反馈及时度**（半幅驾驶舱指针仪表盘）。
- 图表：各部门项目数量（环形 + 引导线）、各负责人项目数量（冷色系多色柱状）。

### 7. 关键缺陷修复
- **反馈闭合误判**：反馈事项本身继承 pending 状态，曾被误算作「未闭合待办」。统一在 `hasUnclosedPending` 与总览问号判定中增加 `!e.reply_to` 条件——反馈记录不再被当作待办，问号/统计恢复准确。
